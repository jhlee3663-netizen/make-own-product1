# Smart Pin v7 설치

1. 압축을 풀고 `manifest.json`, `code.js`, `ui.html`을 같은 폴더에 둡니다.
2. Figma → Plugins → Development → Import plugin from manifest에서 이 폴더의 `manifest.json`을 선택합니다.
3. 먼저 작업 파일의 복제본에서 확인하세요. 새 핀은 작성자 ID를 기록하며, 기존 핀은 작성자 미상으로 보존됩니다.
4. 헤더의 ‘관리’(톱니) → ‘팀 권한 및 관리자’에서 팀이 합의한 관리자를 등록하세요. 기존 핀은 작성자 등록 요청을 승인하거나 관리자가 소유권을 지정할 수 있습니다.
5. 팀원 모두 세 파일을 함께 교체하세요. 구버전에는 권한 보호가 없습니다.

작성자/공동 편집자 편집, 보호 잠금, 상태 담당자, 요청/의견, 수정 이력, 소유권 이전, 휴지통/복구/실행 취소, 백업을 제공합니다. 휴지통은 자동 소거하지 않습니다.

이는 Smart Pin 내부의 협업 권한입니다. Figma 파일 편집자가 캔버스를 직접 조작하는 권한까지 제한하지 않습니다. 배지가 사라져도 글은 보존됩니다.

자동 테스트 26개, 타입 검사, 빌드, Chrome UI 검증을 통과했습니다. Figma API는 모의 환경에서 검증했으며 실제 Figma 두 계정 동시 사용과 Undo/Redo는 추가 확인 대상입니다. 온라인 게시나 팀원 설치는 수행하지 않았습니다.
