# 피드·친구 IA (정보 구조)

> 코치 탭을 **피드 탭**으로 바꾸고 친구·유튜브 가져오기를 넣을 때의 화면 구조와 흐름.
> 시안: `preview/feed-concepts.png`, `preview/profile-concept.png`, `preview/friends-concepts*.png`
> 작성 2026-10-15. 정해지지 않은 건 맨 아래 "정할 것"에 모았다.

## 0. 지키는 규칙 (사용자 입장)

1. **어디서든 사람 이름·사진을 누르면 그 사람 프로필로 간다.** 예외 없음. (스토리 동그라미만 스토리를 연다)
2. **"가져오기"는 어디서 누르든 같은 화면으로 이어진다.** (8장) 출처만 다르다.
3. **막다른 화면이 없다.** 빈 화면에는 항상 다음 할 일 버튼이 있다.
4. **내 기록이 누구에게 보이는지 늘 알 수 있다.** 처음 켤 때 묻고, 마이에서 언제든 바꾼다.
5. **모르는 사람은 내 기록을 못 본다.** 친구가 되어야 기록이 보인다.
6. **실존 인물·유튜버의 프로필을 우리가 만들지 않는다.** 유튜브는 "채널"로만, 밖으로 연결.
7. **친구 기능을 안 켜도 피드 탭은 쓸모가 있다.** (큐레이션 + 유튜브 가져오기)

## 1. 전체 구조

```
하단 내비: 홈 | 피드 | (+기록) | 분석 | 마이        ← 코치 자리에 피드
│
├─ 홈
│   ├─ (기존) 날짜·주간·운동/식단 탭·카드
│   └─ [새] 오른쪽 위 종 → 알림
│
├─ 피드
│   ├─ 위: 검색 버튼 · 친구 초대 버튼
│   ├─ 스토리 줄 (오늘 기록한 친구)
│   ├─ 유튜브 루틴 가져오기 줄
│   └─ 카드 목록: 큐레이션 루틴 · 큐레이션 식단 · 유튜브 루틴 · 친구 루틴 · 친구 기록
│
├─ (+기록)  기존 그대로: 운동 메모 / 식단
│
├─ 분석     기존 그대로
│
└─ 마이
    ├─ [새] 내 프로필 (보기 → 편집)
    ├─ [새] 친구 관리 (친구 목록 · 받은 요청 · 차단 목록)
    ├─ [새] 공개 범위
    ├─ [새] 알림 설정
    └─ (기존) 목표 · 계정 · AI 연결 · 휴지통 · 탈퇴

공통 화면 (어느 탭에서든 위로 열림)
├─ 검색
├─ 프로필 (나 / 친구 / 친구 아님 / 차단함 / 탈퇴함)
├─ 스토리 보기
├─ 기록 상세 (친구 기록 + 박수 + 댓글)
├─ 루틴 상세
├─ 식단 상세 (큐레이션)
├─ 유튜브 가져오기
├─ 채널 페이지
├─ 가져오기 확인 (무게 맞추기 · 끼니 고르기)
├─ 알림
└─ 초대 받기 (링크로 들어왔을 때)
```

## 2. 피드 탭

| 영역 | 내용 | 누르면 |
|---|---|---|
| 위쪽 | "피드" · 🔍 · + 초대 | 🔍 검색(3장) / 초대 공유 시트(6장) |
| 스토리 줄 | 맨 앞 "내 기록", 그 뒤 오늘 기록한 친구들. 안 본 것 먼저, 본 것은 테두리 흐리게 | 내 것: 오늘 기록 있으면 내 스토리, 없으면 운동 메모 열기 / 친구: 스토리 보기(10장) |
| 유튜브 줄 | "유튜브 루틴 가져오기 · 붙여넣기" | 유튜브 가져오기(7장) |
| 카드 | 아래 표 | 카드 본문 → 상세 / 가져오기 버튼 → 가져오기 확인(8장) / 이름 → 프로필 / 채널명 → 채널 페이지 |

**카드 종류**

| 카드 | 출처 표시 | 가져오기 버튼 | 누가 봄 |
|---|---|---|---|
| 큐레이션 루틴 | Context Health 큐레이션 | 내 메모로 가져오기 | 모두 |
| 큐레이션 식단 | Context Health 큐레이션 · 식단 | 내 식단으로 가져오기 | 모두 |
| 유튜브 루틴 | 유튜브 · 채널명 · ○○이 가져옴 | 내 메모로 가져오기 | 모두 (올린 사람이 "피드에 올리기" 했을 때만) |
| 친구 루틴 | 친구 이름 · 루틴 | 내 메모로 가져오기 | 그 사람의 친구 |
| 친구 기록 | 친구 이름 · 오늘/날짜 | 이 운동 가져오기 | 그 사람의 친구 |

**순서**: 최신순. 단, 친구 카드가 큐레이션 카드에 묻히지 않게 위쪽 몇 개 안에 친구 카드를 섞는다. (정할 것 ①)

**피드 상태**

| 상태 | 보이는 것 |
|---|---|
| 친구 0명 | 스토리 줄 자리에 "같이 운동하는 친구를 불러보세요 · 초대하기" 한 줄. 카드는 큐레이션·공개 유튜브만 |
| 친구는 있는데 오늘 아무도 안 함 | 스토리 줄에 "내 기록"만 + "오늘은 아직 아무도 안 했어요" |
| 카드를 끝까지 봄 | "다 봤어요 · 유튜브에서 루틴 가져오기" |
| 불러오기 실패 | "피드를 불러오지 못했어요 · 다시 시도" (기존 내용은 남겨 둠) |
| 오프라인 | 마지막으로 본 피드 + 위쪽에 "연결이 끊겼어요" |

## 3. 검색

들어오는 곳: 피드 위쪽 🔍, 마이 › 친구 관리 위쪽 🔍

```
검색
├─ 입력 전: 최근 검색어 · 내 친구 전체(가나다순)
└─ 입력 후: 탭 3개
    ├─ 사람   1) 내 친구 중 이름·아이디가 맞는 사람  2) 아이디가 정확히 같거나 앞부분이 같은 다른 사람
    ├─ 루틴   큐레이션 · 공개된 유튜브 루틴 · 내 친구의 루틴 (제목·종목·부위)
    └─ 채널   유튜브 채널명
```

| 경우 | 처리 |
|---|---|
| 친구 이름으로 찾기 | 내 친구 목록 안에서 이름(표시 이름)으로 바로 걸림 |
| 친구 아닌 사람 | **아이디로만** 걸림. 이름으로는 안 걸림 (모르는 사람이 이름으로 나를 찾지 못하게) |
| 결과 없음 | "○○를 찾지 못했어요" + 사람 탭이면 "초대 링크 보내기" |
| 나를 차단한 사람 / 내가 차단한 사람 | 결과에 안 나옴 (차단 목록에서만 보임) |
| 탈퇴한 사람 | 안 나옴 |

## 4. 프로필

### 4-1. 프로필에 들어오는 곳
스토리 화면 위 사진·이름 / 피드 카드의 이름 / 기록 상세·댓글의 이름 / 알림 / 검색 결과 / 친구 목록 / 초대 받기 화면

### 4-2. 관계별로 보이는 것

| 관계 | 위쪽 | 버튼 | 기록 탭 | 루틴 탭 | 최고 기록 탭 |
|---|---|---|---|---|---|
| **나** | 사진·이름·아이디·소개·숫자 | 프로필 편집 · 공개 범위 | 내 기록 전체 | 내 루틴 (공개/비공개 표시) | 내 최고 기록 |
| **친구** | 같음 | 친구 ✓(누르면 끊기·차단 메뉴) · 콕 찌르기 | 공개 범위만큼 | 공개한 루틴 | 공개했으면 보임 |
| **친구 아님** | 사진·이름·아이디·소개 | 친구 요청 | 🔒 "친구가 되면 볼 수 있어요" | 공개한 루틴만 | 🔒 |
| **내가 요청 보냄** | 같음 | 요청 보냄(누르면 취소) | 🔒 | 공개 루틴 | 🔒 |
| **나에게 요청 옴** | 같음 | 수락 · 거절 | 🔒 | 공개 루틴 | 🔒 |
| **내가 차단함** | 이름만 | 차단 해제 | 안 보임 | 안 보임 | 안 보임 |
| **나를 차단함** | "찾을 수 없는 사용자예요" (차단 사실을 알리지 않음) | 없음 | – | – | – |
| **탈퇴함** | "탈퇴한 사용자예요" | 없음 | – | – | – |

숫자: 운동 횟수 · 루틴 수 · 친구 수. 친구 수를 누르면 친구 목록 — **본인 것만** 열림. 남의 친구 목록은 안 보여줌 (정할 것 ②).

### 4-3. 내 프로필 편집 (마이 › 내 프로필 › 편집)
- 사진 (앨범에서 고르기 / 기본 아바타 / 삭제)
- 표시 이름 (중복 가능, 최대 12자)
- 아이디 (중복 불가, 영문 소문자·숫자·밑줄·점, 3–20자, 바꾸면 30일 동안 다시 못 바꿈) — 입력하면서 "사용 가능 / 이미 있음" 바로 표시
- 한 줄 소개 (최대 40자)
- 저장 전에 뒤로 가면 "수정한 내용을 버릴까요?"

### 4-4. 처음 친구 기능을 쓸 때 (프로필이 없을 때)
초대 / 친구 요청 / 피드에 올리기 중 **처음 하는 순간**에 한 번:
1. 아이디·사진 정하기 (표시 이름은 가입 이름으로 채워 둠)
2. 공개 범위 확인 (기본: 운동만 친구에게)
3. 원래 하려던 일로 돌아감

피드를 보기만 하는 사람에게는 묻지 않는다.

### 4-5. 루틴 탭 · 최고 기록 탭은 어떻게 채우나
- **루틴**: 앱이 기록에서 반복되는 부위 조합을 찾아 **초안**을 만든다 → 내 프로필 루틴 탭에 "초안 2개 · 확인하고 올리기"로만 보임 → 본인이 이름·종목을 고치고 "공개"해야 친구에게 보임. 직접 새로 만들기도 가능.
- **최고 기록**: 기록에서 종목별 최고 무게(와 그때 횟수)를 자동 계산. AI 안 씀. 본인이 특정 기록을 숨길 수 있음 (잘못 적은 기록 대비).

## 5. 친구 관계

```
없음 ──요청──▶ 요청 보냄 ──상대 수락──▶ 친구
  ▲              │ 취소/상대 거절            │ 끊기
  └──────────────┘◀─────────────────────────┘
초대 링크로 들어와 수락 → 바로 친구 (요청 단계 없음)
어느 상태에서든 차단 → 차단 (친구였다면 끊김, 요청은 사라짐)
```

| 경우 | 처리 |
|---|---|
| 거절 | 상대에게 알리지 않음. 상대 화면에선 "요청 보냄"이 조용히 "친구 요청"으로 돌아감 |
| 같은 사람에게 다시 요청 | 거절당한 뒤 7일 동안 못 보냄 (정할 것 ③) |
| 서로 동시에 요청 | 자동으로 친구 |
| 끊기 | 상대에게 알리지 않음. 서로의 스토리·기록·친구 카드가 바로 사라짐. 주고받은 박수·댓글은 남되 이름은 그대로 |
| 차단 | 서로 검색·프로필·피드·알림·댓글에서 사라짐. 차단당한 쪽은 모름 |
| 친구 수 한도 | 100명 (정할 것 ④) |
| 탈퇴 | 모든 관계 삭제. 남긴 댓글은 "탈퇴한 사용자" |

## 6. 초대 링크

**보내기**: 피드 + 초대 / 친구 0명 화면 / 마이 › 친구 관리 → 공유 시트 (카카오톡 · 링크 복사 · 기타)
링크 하나 = 나를 친구로 추가하는 링크. 여러 명이 써도 됨. 7일 뒤 만료, 마이에서 새로 만들 수 있음.

**받은 사람이 링크를 열었을 때**

| 받은 사람 상태 | 흐름 |
|---|---|
| 앱 설치 + 로그인 | 앱 열림 → 초대 받기 시트 ("민수님이 초대했어요 · 보이는 것: 운동") → 수락 → 프로필 없으면 4-4 → 친구 → 민수 프로필 |
| 앱 설치 + 로그아웃 | 로그인 → 초대 받기 시트 (링크 기억해 둠) |
| 앱 없음 / 웹 처음 | 웹에서 열림 → 초대한 사람 미리보기 + "시작하기" → 가입·온보딩 → 초대 받기 시트 |
| 이미 친구 | "이미 친구예요" → 그 사람 프로필 |
| 내 링크를 내가 엶 | "내 초대 링크예요 · 공유하기" |
| 만료된 링크 | "기간이 지난 초대예요" + 그 사람 아이디로 친구 요청 보내기 |
| 초대한 사람이 탈퇴 / 나를 차단 | "찾을 수 없는 초대예요" |
| 친구 한도 꽉 참 | 수락 시 "친구가 가득 찼어요 · 정리하기" |
| 다음에 | 시트 닫힘. 알림 목록에 "민수님의 초대"로 남아 다시 수락 가능 |

## 7. 유튜브 가져오기

들어오는 곳: 피드의 유튜브 줄 / 운동 메모 화면의 "유튜브에서" (정할 것 ⑤) / 휴대폰 공유 시트로 앱에 링크 보내기 (설치한 앱만, 나중)

```
링크 붙여넣기 (클립보드에 유튜브 링크가 있으면 미리 채워 둠)
→ 정리 중 (썸네일·제목 먼저 보이고, 아래에서 정리 진행) — 나가도 됨, 끝나면 알림
→ 결과: 종목 · 영상 시간 · 영상 속 무게/세트 · 내 무게로 맞춘 값 · 영상 속 팁
   ├─ 종목 이름 고치기 / 빼기 / 순서 바꾸기
   ├─ 오늘 메모로 가져오기 → 8장
   ├─ 나중에 쓰기 (내 루틴에 저장)
   └─ 피드에도 올리기 (선택, 기본 꺼짐)
```

| 실패·예외 | 보이는 것 |
|---|---|
| 유튜브 링크가 아님 | 붙여넣는 순간 "유튜브 링크만 가져올 수 있어요" |
| 비공개·삭제·연령 제한 영상 | "볼 수 없는 영상이에요" |
| 운동 영상이 아님 / 종목을 못 찾음 | "이 영상에서 운동 루틴을 찾지 못했어요" + 직접 메모 쓰기 |
| 너무 긴 영상 (예: 60분 넘음) | "60분 이하 영상만 가져올 수 있어요" (비용 한도, 정할 것 ⑥) |
| 누가 이미 가져온 영상 | AI를 다시 안 돌리고 저장된 정리 결과를 바로 보여줌 (무게 맞춤만 내 기준으로 새로) |
| AI 사용량 한도 | 기존 문구 그대로 ("약 N분 뒤에 다시") |

## 8. 가져오기 (공통)

출처: 큐레이션 루틴 / 유튜브 루틴 / 친구 루틴 / 친구 기록 / 스토리 / 내 저장 루틴

**운동 → 무게 맞추기 시트**
- 위쪽 선택: 내 기록 기준(기본) / 원래 무게 그대로 / 무게 비우기
- 종목마다 무게 정하기: ① 내가 한 적 있는 종목 → 내 지난번 무게 ② 처음 하는 종목 → 출처와 나의 공통 종목 무게 비율로 추정, "추정" 표시 ③ 둘 다 없으면 "직접 입력"
- 세트·횟수는 출처 그대로
- "오늘 메모로 가져오기" → 운동 메모 화면이 채워진 채로 열림 (저장은 평소처럼 사용자가)

| 경우 | 처리 |
|---|---|
| 오늘 이미 운동 메모가 있음 | "오늘 메모 뒤에 붙일까요, 새 메모로 열까요?" |
| 메모를 쓰던 중 (저장 안 함) | "쓰던 메모 뒤에 붙일게요" (덮어쓰지 않음) |
| 가져와 놓고 저장 안 하고 나감 | 기존 메모 화면 규칙 그대로 (임시 저장) |
| 출처가 사라짐 (친구 끊김·삭제) | 이미 가져온 건 내 것으로 남음 |

**식단 → 끼니 고르기 시트**
- 하루 식단이면 끼니별로 체크 (아침·점심·저녁 각각 넣을지)
- 넣을 날짜: 오늘 (지난 날짜는 기존 규칙대로 기록 있을 때만)
- 이미 그 끼니에 음식이 있음 → 뒤에 추가

가져오면 출처에 "○명이 가져갔어요" +1. 친구 것을 가져오면 그 친구에게 알림.
