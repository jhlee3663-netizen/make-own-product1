# PC 데이터 표시 깨짐 핫픽스

2026-09-08 운영 PC 화면에서 한글과 수치가 겹치거나 잘못 그려지는 장애를 확인해 P1로 분류하고 핫픽스를 배포했다. 모바일에서는 재현되지 않았으며 모바일 애니메이션은 유지했다. 운영 데이터와 Firebase Auth·Firestore 설정은 변경하지 않았다.

## 판정과 원인 범위

- DOM의 식단 칼로리·탄단지·날짜와 운동 제목 값은 정상인데 화면 픽셀만 깨졌다. 데이터 손상이나 잘못된 조회로 분류하지 않는다.
- PC 1920px에서 식단 카드 48개가 모두 `cardUp`의 최종 `transform`을 `forwards`로 유지했고, 상위 `.tab-panel`도 `will-change: transform`으로 계속 합성 계층에 남았다.
- 1차 수정은 위 합성 계층만 해제했으나 굵은 한글과 SVG 차트 글자가 일부 계속 깨졌다. 1차 정상 판정은 잘못이었으며 재검증 뒤 철회했다.
- PC의 Pretendard 렌더링 경로를 시스템 한글 글꼴로 바꾸자 동일 운영 데이터와 50개 반복 fixture에서 깨짐이 해소됐다. 브라우저의 정확한 내부 원인은 직접 계측하지 못했으므로 ‘Pretendard 파일 자체 결함’으로 단정하지 않는다.
- 1차 CSS 전용 배포본을 만들 때 Workbox precache 목록만 복제해, 앱이 직접 참조하지만 precache되지 않은 `/logo.png`를 빠뜨렸다. 이 패키징 실수로 로고가 깨졌고 V2에서 원본 PNG를 복구했다.

## 재현 단계

1. PC Chrome에서 `https://context-health-3eb84.web.app/`을 1920px 폭으로 연다.
2. 로그인된 홈의 쇠질 탭에서 주간 그래프와 여러 운동 카드를 확인한다.
3. 식단 탭으로 이동해 주간 그래프, 칼로리, 탄수화물·단백질·지방 수치를 확인한다.
4. 수정 전에는 한글·숫자가 겹치거나 뒤집힌 모양으로 그려졌다. 접근성/DOM 텍스트는 올바른 값이었다.
5. 개발자 계산 스타일에서 카드의 `animation-fill-mode: forwards`, 최종 transform matrix, 탭의 `will-change: transform`을 확인한다.

## 수정

PC 폭(`min-width: 640px`)에서 다음을 함께 적용했다.

1. 카드 진입 애니메이션과 탭의 상시 `will-change`를 해제한다.
2. 본문·폼·`.font-pretendard`·SVG text를 OS 시스템 한글 글꼴로 렌더링한다.
3. 누락됐던 `/logo.png` 원본을 Hosting과 서비스워커 precache에 복구한다.

모바일 폭에는 기존 Pretendard와 애니메이션 규칙을 그대로 적용한다. 소스 수정은 [`src/index.css`](../../../src/index.css)에 반영했다.

운영 배포는 현재 라이브 JS와 기본 CSS를 그대로 복제한 별도 Firebase Hosting 미리보기에서 수행했다. V2에서 JS·기본 CSS·복구 로고의 SHA-256과 새 override CSS, 서비스워커 목록을 확인한 뒤 라이브 채널로 승격했다. 따라서 작업 폴더의 QA-02 및 다른 미배포 코드는 이번 운영 핫픽스에 포함되지 않았다.

## 검증 결과

| 조건 | 결과 | 증거 |
|---|---|---|
| PC 1920px 쇠질 | 정상 | 로고·연속 기록·주간 볼륨·운동 카드·AI 문구를 운영 화면에서 육안 확인 |
| PC 1920px 식단 | 정상 | 48개 카드 DOM 상태에서 오늘 칼로리·주간 그래프·도넛·탄단지·날짜 정상 |
| PC 1920px AI 코치 | 정상 | 추천 문구·대화방 제목·설명 정상, 문제 글꼴 우회 계산값 확인 |
| PC 1920px 마이 | 정상 | 프로필·목표·수치·계정 메뉴 정상, 문제 글꼴 우회 계산값 확인 |
| 반복 fixture | 정상 | 같은 CSS로 카드 50개·SVG text·로고를 데스크톱과 390px에서 확대 캡처 |
| 모바일 390px | 정상 | PC 전용 media query 미적용, 기존 카드 animation과 탭 전환 규칙 유지 |
| 배포 범위 | CSS/PWA 갱신으로 제한 | 운영 JS와 기본 CSS SHA-256 배포 전후 동일 |
| 운영 데이터 | 쓰기 없음 | 화면 이동·조회·계산 스타일 확인만 수행 |

기계 판독 가능한 값과 해시는 [desktop-render-hotfix.json](evidence/desktop-render-hotfix.json)에 있다. 기존 서비스워커가 이전 HTML을 한 번 제공한 탭은 새 서비스워커 설치 뒤 한 번 더 새로고침해야 V2 CSS가 적용될 수 있다.

## 남은 확인

실제 Windows GPU/Chrome·Edge와 macOS Safari 장시간 사용 후 재발 여부는 별도 기기 검증이 필요하다. 현재 운영 Chrome의 PC·모바일 폭에서는 재현이 해소됐다. 전체 PWA 오프라인/업데이트 여정은 이 핫픽스 한 건으로 통과 처리하지 않는다.
