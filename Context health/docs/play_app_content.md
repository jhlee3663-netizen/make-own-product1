# 「데이터 안전」 섹션 답변

## 공통 선언

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | **예 (수집함)** |
| 제3자와 **공유**하나요? | **아니요** — Firebase·Gemini·Sentry는 모두 서비스 제공업체(처리 위탁)라 Play 기준의 '공유'가 아님 |
| 전송 중 암호화되나요? | **예** (전부 HTTPS/TLS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** (앱 내 탈퇴 + 삭제 요청 URL) |
| 독립적인 보안 검토를 받았나요? | **아니요** |

## 수집하는 데이터 항목

아래는 전부 **수집됨 / 공유 안 함 / 암호화 전송 / 삭제 요청 가능**.

| 카테고리 | 세부 유형 | 필수·선택 | 목적 |
|---|---|---|---|
| 개인 정보 | 이름 | 필수 | 계정 관리, 앱 기능 |
| 개인 정보 | 이메일 주소 | 필수 | 계정 관리 |
| 개인 정보 | 사용자 ID (UID) | 필수 | 계정 관리, 앱 기능 |
| 사진 및 동영상 | 사진 | **선택** | 앱 기능 (프로필 사진, 피드 게시물) |
| 건강 및 피트니스 | 건강 정보 | 필수 | 앱 기능, 분석 |
| 건강 및 피트니스 | 피트니스 정보 | 필수 | 앱 기능, 분석 |
| 앱 활동 | 기타 사용자 생성 콘텐츠 | 필수 | 앱 기능 (운동·식단 메모, AI 대화) |
| 앱 정보 및 실적 | 비정상 종료 로그 | 필수 | 분석 (Sentry) |
| 앱 정보 및 실적 | 진단 | 필수 | 분석 (Sentry) |
| 기기 또는 기타 ID | 기기 또는 기타 ID | 필수 | 앱 기능 (FCM 푸시 토큰) |

**수집하지 않는 것** (체크하지 말 것): 위치, 금융 정보, 전화번호, 주소, 연락처, 캘린더,
메시지(SMS), 오디오, 음성, 파일·문서, 웹 탐색 기록, 설치된 앱 목록.

## 주의할 점

- '공유'를 **예**로 찍으면 안 된다. 소셜 피드에서 다른 이용자에게 보이는 건
  Play 기준의 '공유(제3자 회사에 전송)'가 아니라 앱 기능이다.
- '건강 및 피트니스'는 민감 항목이라 개인정보처리방침에 반드시 명시돼 있어야 한다
  (처리방침 3항에 민감정보 조항 있음 — OK).
- 수집 항목이 바뀌면(예: 위치 기능 추가) 이 섹션을 먼저 고쳐야 업데이트가 통과된다.
